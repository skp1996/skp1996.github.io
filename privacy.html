Privacy Policy: CyberShield Studio

Last updated: 9 November 2026

CyberShield Studio ("the app") is a private tool that the owner of the Cybershield Academy YouTube channels uses to publish their own videos. It runs only on the owner's own computer. It is not offered to the public, and nobody else signs in to it.

Information the app accesses

When the channel owner signs in with Google, the app requests these YouTube permissions:

  • youtube.upload: to upload the owner's videos to the owner's channels.
  • youtube.force-ssl: to read the owner's channel details and the status of the owner's videos, and to manage the owner's own subtitles, thumbnails, playlists, video descriptions, channel description and banner.

The app does not access any other person's data, viewers' personal data, comments, contacts, email or files.

How information is used

This information is used only to publish and manage the owner's own videos and channels. It is not used for advertising, profiling or any other purpose.

Storage and security

The Google sign-in tokens are stored only on the owner's computer, encrypted with Windows data protection (DPAPI). Nothing is sent to any server other than Google's own YouTube Data API.

Sharing

The app does not sell, rent, share or transfer any Google user data to anyone.

Google API Services User Data Policy

CyberShield Studio's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's token files on the owner's computer also removes the stored sign-in.
